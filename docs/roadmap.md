# ロードマップ

目標: Pebble Index 1 のような指輪型の常時装着録音デバイスを
Seeed Studio XIAO nRF52840 Sense で作る。

USB接続で1つずつ機能を確認してから、最後にバッテリ駆動の指輪筐体へ移行する。

---

## Phase 0 — 環境構築 ✅

- `Seeeduino:nrf52` コア（非mbed / Adafruit Bluefruit ベース）を採用
- `scripts/` にビルド・書き込み・シリアルツールを用意

**mbed版ではなく非mbed版を選んだ理由**: BLE（Bluefruit）、FreeRTOS、
`InternalFileSystem`、TinyUSBのマスストレージ、`sd_app_evt_wait()` による
低消費電力待機がすべて標準で揃う。Phase 3〜5 でこれらが全部必要になる。
mbed版はPDMマイクのサンプルが豊富という利点はあるが、電池駆動の
指輪用途では消費電力とサイズで不利。

## Phase 1 — 模擬ボタン ✅

実ボタンをまだ配線していないので、USBシリアルからボタンの押下波形を
注入して状態機械とLED表示を動かす。

- `ButtonSource` で入力を抽象化（virtual ⇄ gpio を差し替え可能に）
- `PressDetector` にデバウンス・長押し・ダブル押し判定を集約
- `RecorderApp` に SLEEP / IDLE / RECORDING の状態機械
- 実測: 長押しは押下から 800ms ちょうどで発火、短押しは
  ダブル押し待ち 350ms 後に確定

**ここで詰めておく価値**: 操作の作法（何回押しで何が起きるか、長押しの
しきい値、フィードバックのタイミング）は指輪では画面が無いぶん決定的に
重要で、ハードが無くても今すべて詰められる。

## Phase 2 — マイク性能確認

- PDM（PWR=19 / CLK=20 / DIN=21）から 16kHz / 16bit モノラルを取得
- シリアルにレベルメータと簡易スペクトルを出し、以下を実測する
  - 無音時のノイズフロア、クリップするまでの距離と声量
  - 指輪として手に装着した状態での擦れ音・ハンドリングノイズ
  - AGC / ハイパスフィルタの要否
- 判断ポイント: **サンプルレートを16kHzに落とせるか**。
  音声認識用途なら16kHzで十分で、容量も消費電力も大きく下がる。

## Phase 3 — 録音パイプライン

- ボタン押下 → PDM開始 → リングバッファ → 2MB QSPIフラッシュへ書き出し
- WAVヘッダを付けてファイル化、マーカー位置も記録
- TinyUSB マスストレージでUSB接続時に「USBメモリ」として見せ、
  Macから録音ファイルを直接コピーできるようにする
- 容量の目安: 16kHz/16bit 無圧縮で 2MB ≒ **約65秒**。
  ここで圧縮が必須だと分かるので Phase 4 に繋がる

## Phase 4 — 圧縮とBLE転送

- 圧縮候補: IMA ADPCM（4倍、CPU負荷小）/ Opus（10倍以上、要CPU）
  - まず ADPCM で 2MB ≒ 約4分を確保し、足りなければ Opus を検討
- BLE で iPhone / Mac へ転送（Nordic UART Service か独自の
  Notify ベース。実効スループットは 20〜100kbps 程度）
- 「録音は端末に貯めて、あとでまとめて転送」がバッテリ的に有利

## Phase 5 — 低消費電力化とバッテリ

- 待機は `sd_app_evt_wait()`、深いスリープは System OFF + GPIO ウェイク
- 未使用ペリフェラル（IMU、外部フラッシュのディープパワーダウン）を停止
- LEDは常時点灯をやめ、短いパルスに（指輪では消費の大きな割合になる）
- バッテリ残量: VBAT_ENABLE(14) を LOW → PIN_VBAT(32) を ADC 読み取り
- 充電: オンボード BQ25101。P0.13 で 50mA / 100mA を切替（小容量セルは50mA）
- 電流実測が必要な区間: 待機 / 録音中 / BLE転送中

**指輪サイズの現実的な制約**: 入る電池は 15〜40mAh 程度。
待機 100µA・録音 5mA としても、録音は連続で数時間、待機で数日。
ここが設計全体を縛るので、Phase 2〜4 の各段階で電流を測っておく。

## Phase 6 — 指輪筐体化

- 実ボタン: タクトスイッチ、もしくは nRF52840 内蔵の
  静電容量タッチ（外付け電極）。`GpioButtonSource` を差し替えるだけで済む
- マイク穴の音響設計（穴径・キャビティ・防水メッシュ）
- XIAO は 21×17.5mm。指輪に入れるには**基板の再設計（nRF52840モジュール
  単体 + 自作基板）がほぼ必須**。XIAO のままだと指輪ではなくペンダント型が現実的
- 中間ゴールとして「ペンダント型で完成させる → 指輪サイズに縮小」を推奨
