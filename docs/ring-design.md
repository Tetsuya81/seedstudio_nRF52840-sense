# v1 指輪の物理設計（XIAO をそのまま TPU リングに収める）

添付写真の方針にもとづく設計メモ。

- 素材: **Bambu Lab TPU 95A HF**
- 構成: リング幅を太くして XIAO 基板を頂部に収納、基板の両脇にバッテリー
- 操作: **物理ボタン**、状態表示は**基板のRGB LED**（ディスプレイなし）

**この方針の一番大きい効果は、v1 で自作基板が要らなくなること。**
XIAO をそのまま使えるので、今あるハードだけで最後まで組める。

---

## 1. 寸法と成立性

| 項目 | 値 |
|---|---|
| XIAO nRF52840 Sense | 21 × 17.5 × 約3.5mm（USB-C込み） |
| 重量 | 3.3g（メーカー表記・梱包込み。基板単体は2g前後） |
| 想定する人差し指 | 直径 φ19mm（R=9.5mm）／周長 約60mm |

### 基板の向き

写真の向き（**21mm を指の軸方向、17.5mm を指の周方向**）が正解。
逆にすると 21mm が周方向になるが、指の直径19mmを超えるため
基板が横にはみ出して収まらない。

### 完成時の外形（概算）

```
指の中心から:  9.5 (指) + 1.0 (基板下の空隙) + 3.5 (基板) + 1.5 (TPU外壁) = 15.5mm
→ 指の頂点から外側へ 約6mm 出っ張る
→ リング幅（指の軸方向）は 21 + 壁2×1.5 = 約24mm
```

幅24mmは基節骨のほぼ全長を覆う。太めだが、写真の方針どおり。

### 重量の見込み

XIAO 約2g + バッテリー 約1g + TPU 約2〜3g = **約5〜6g**。
一般的な結婚指輪が3〜6g、Oura Ring が4〜6g なので、常時装着できる範囲に収まる。

## 2. バッテリー室 — 「基板の脇」は幾何学的に正しい

平らな基板を丸い指の頂点に接して置くと、基板の端に向かって
くさび形の空隙ができる。**そこがそのままバッテリー室になる。**

基板端（中心から 8.75mm）での指表面との隙間:

```
gap = R − √(R² − x²) = 9.5 − √(9.5² − 8.75²) = 9.5 − 3.70 = 5.8mm
```

片側のくさび断面積は約 **14.1mm²**、基板長 21mm をかけて
**約296mm³／片側、両側で約590mm³**。外壁を膨らませればさらに増える。

**収まるセルの例**: 2.0 × 12 × 20mm 級（約480mm³、20mAh前後）が片側に1枚。
両側に1枚ずつ入れて並列にすれば **約40mAh**。左右対称になるので重量バランスも良い。

> 並列にするなら同一型番・同一充電状態のセルを恒久接続で使うこと。
> 異なるセルの並列は避ける。

### 稼働時間の見込み（40mAh、実用32mAh として）

| 状態 | 電流 | 持続 |
|---|---|---|
| 録音中 | 5〜8 mA | **約5時間** |
| 待機（System OFF + ボタン復帰） | 30〜50 µA | 約26日 |

### ⚠️ v1 で先に尽きるのは電池ではなく保存容量

XIAO のフラッシュは 2MB しかない。16kHz/16bit モノラルで:

| 保存方式 | 2MB で録れる長さ |
|---|---|
| 無圧縮 PCM | 65秒 |
| IMA ADPCM (4:1) | **4.4分** |
| Opus 16kbps | 17.5分 |

電池は5時間もつのに、**保存は数分で頭打ち**になる。
これが v1 の設計上いちばん効く制約。指輪型を選んだことで
電池の心配が減った代わりに、容量が前面に出てきた。

### ⚠️ 充電電流

XIAO 搭載の BQ25101 は P0.13 で切り替える:

| P0.13 | 充電電流 |
|---|---|
| HIGH（既定） | 50mA |
| LOW | 100mA |

40mAh のパックに 50mA は **1.25C**。小型セルの多くは 0.5C 上限なので、
**1C以上の充電に対応したセルを選ぶ**か、合計容量を50mAh以上にする。
**100mA 設定は絶対に使わない**（2.5C になる）。

## 3. 物理ボタン

`GpioButtonSource` は Phase 1 で実装済み。配線してピンを指定するだけで動く。

- **配線**: タクトスイッチを **D1 (P0.03)** と **GND** の間に。`INPUT_PULLUP` 前提。
  D1 は IMU (D4/D5)、マイク (P1.08/09/10)、外部フラッシュのどれとも競合しない
- `firmware/pebble_ring/config.h` の `PIN_USER_BUTTON` は既に `D1`
- 実行時に `g` コマンドで virtual ⇄ gpio を切り替えて確認できる
- System OFF からの復帰も GPIO の DETECT で可能

### TPU との相性が良い点

**タクトスイッチの上に 0.8〜1.0mm の TPU 膜を一体で成形すれば、
その膜自体がボタンになる。** 別部品もパッキンも要らず、防水も同時に満たす。
Shore 95A は押し込める硬さなので、これは TPU を選んだことの直接の利点。

## 4. LED による状態表示

Phase 1 の表示設計はそのまま使える（消灯=SLEEP／緑ちらつき=IDLE／赤点灯=REC／青=マーカー）。

- **LED窓**: 天面の肉厚を 0.6〜0.8mm まで落とすか、透光性のある色の TPU にする。
  TPU は拡散が効くので、うまくいけば面発光のように見える
- **消費電力**: 12〜32mAh しかないので LED の常時点灯は禁物。
  IDLE 表示を「2秒に1回 40ms の緑」にしてあるのはこのため

### ✅ 組む前に確認すること

**LED が基板のどちら側に載っているか**を目視で確認する。
シリアルで `x` を送ると 赤→緑→青→白 の順に点灯するので、
どちらの面が光るか見れば確実に分かる。**光る面を外側に向ける。**

---

## 5. マイクの音道 ⚠️

**最大の未確認事項**。XIAO Sense の PDM マイクが基板のどちら側に載っているかで
設計が変わる。写真の向きだと、マイクが裏面（指側）にある場合は指で塞がれる。

### 対策: 基板を指から浮かせて、その空隙を外側へ導く

```
        TPU外壁 ─┬── LED窓(薄肉)
    ┌────────────┴────────────┐
    │        XIAO 基板         │
    └──┬──────────────────┬───┘
  電池 │   1mm の空隙      │ 電池
       └──→ ダクト ──→ 側面の小穴（音響メッシュ）
```

- 基板下に **1mm の空隙**を作る棚を TPU 側に設ける。
  そもそも PCB を素肌に当てないほうが、汗・腐食・装着感のすべてで良い
- その空隙を側面の小穴へ短く太いダクトで導く
- 穴には防水の音響メッシュを貼る

**ただしキャビティ＋ダクトはヘルムホルツ共鳴を起こして音を色付ける。**
キャビティを小さく、ダクトを短く太くするのが原則で、
**実際にどう効くかは Phase 2 で実測する**。

## 6. アンテナ

**TPU は非導電なので、金属バンド案にあったアンテナ問題はほぼ消える。**
これは素材選択の大きな利点。

残る注意点:

- 皮膚は 2.4GHz を吸収する誘電体なので、装着すると必ず感度は落ちる
- XIAO のオンボードアンテナは基板の端（USB-C の反対側）にある。
  **その端を TPU で厚く覆いすぎない**。金属（電池のアルミラミネート含む）を近づけない
- 電池を左右に置く配置は、アンテナ端を避けられるので都合が良い
- 装着した状態で RSSI を実測して確認する

---

## 7. USB-C をそのまま残す ← v1 最大の簡略化

写真の向きだと USB-C は手の甲側を向いていて、バンドに開口を設ければ露出できる。

**USB-C を残せば、書き込みも充電も従来どおりできる。**

- BLE OTA DFU は **v1 では不要**（v2 の自作基板で必要になったら実装する）
- 充電ドックも接点も不要
- 録音の取り出しは TinyUSB マスストレージで「USBメモリ」として見せられる

指輪型でいちばん厄介な「コネクタが載らない」問題を、
XIAO をそのまま使うことで回避できている。

## 8. TPU 95A HF の実務メモ

- **AMS 非対応**。TPU 95A HF は直接ドライブで給紙する
  （AMS で使えるのは別品番の "TPU for AMS"）
- 吸湿性が高い。**印刷前に必ず乾燥**させる
- 高速TPU で、外壁 80mm/s 程度まで出せる
- **印刷の向き**: リングを「ドーナツを寝かせた向き」で刷ると
  レイヤーが周方向に連続し、指に通すときに伸ばしても裂けにくい
- 基板の収納部は蓋を別パーツにするか、ブリッジを避ける形状にして
  サポート無しで刷れるようにする
- 長時間の肌接触になるので、実際に数日装着してかぶれないか確認する

---

## 9. 組む順番

1. `x` で **LED の載っている面**を確認 → 外向きに決める
2. 基板を目視して **マイクの載っている面**を確認 → 音道の設計を決める
3. タクトスイッチを D1–GND に配線して `g` で実動作を確認
4. モックを印刷して**寸法・装着感・ボタンの押し心地**を先に確認（配線前）
5. バッテリー接続（BAT+ / BAT−、P0.13 は HIGH のまま）
6. 本組み
